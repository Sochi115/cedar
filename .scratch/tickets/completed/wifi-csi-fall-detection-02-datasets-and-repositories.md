# Inventory CSI Fall-Detection Datasets and Repositories

Status: resolved
Type: research
Label: wayfinder:research
Blocked by: none

## Question

Which public datasets and GitHub repositories can support an initial WiFi CSI fall-detection POC?

Investigate first-party dataset pages, dataset papers, and GitHub repositories. For each candidate, capture URL, CSI format, hardware, activities, participant and environment details, licensing or access constraints, labels, preprocessing/tooling, maintenance status, and practical suitability for reproducible POC work. Distinguish genuinely usable CSI resources from references that only mention a dataset or repository.

## Answer

Initial pass documented five candidate resources. ElderAL-CSI and CSI-Bench are potential direct candidates but require access, licensing, format, and label verification. CSI-BFI-HAR may support activity baselines. WiPE-FaLl concerns fall-risk prediction and FallDeWideo combines CSI with video; both are outside the current single-modality fall-event scope. No qualifying GitHub repository was identified in this pass.
