# Wi-Fi CSI datasets for fall detection beyond WiFall

**Scope:** Datasets containing labeled fall episodes, distinguished from fall-risk proxies and generic activity-recognition data. WiFall mirrors are not counted as new datasets. Counts and access details below are source-reported; validate archives and terms before use.

## Related data, not labeled fall events

- **WiPE-FaLl — fall likelihood / mobility proxy.** [University of Glasgow data record](https://researchdata.gla.ac.uk/1623/) and [DOI](https://doi.org/10.5525/gla.researchdata.1623). CSI amplitude from one person performing a Timed Up-and-Go test, recorded with two USRP X300 devices. Labels concern low/medium/high fall risk, not actual falls. Available on request because of file size; stated license is CC BY 4.0. Useful for gait and risk estimation, not fall-event classification without additional labels.
- **Generic Wi-Fi HAR datasets** are omitted unless source establishes fall-event labels. “Fall risk” or an activity class loosely associated with falling is not equivalent to recorded fall episodes.
- **WiFall re-hosts/mirrors** are not new datasets; for example, [Hugging Face RS2002/WiFall](https://huggingface.co/datasets/RS2002/WiFall) should not be counted as independent collection. Use the [original WiFall paper](https://doi.org/10.1109/TMC.2016.2557792) for provenance.

## Recommendation

1. **Best scale and environment diversity:** CSI-Bench, if dataset size and CC BY-NC-ND terms fit. Separate fall-task subset has 17 participants and 6 environments; not clinical or spontaneous-elderly-fall validation.
2. **Best multimodal CSI/pose resource:** FallDeWideo, subject to partial-download friction and unclear data license.
3. **Fastest baseline start:** ENetFall, after confirming data reuse rights and collection provenance.
4. **Potential large collection with access friction:** TCS-Fall; verify IEEE access status, terms, and archive labels first.
5. **ToiFall:** promising task match, but current access evidence is insufficient to recommend as downloadable.
6. **Risk estimation:** WiPE-FaLl is relevant only to fall-risk/mobility assessment.

No source reviewed establishes spontaneous falls by older adults for the listed event datasets. Controlled/scripted collections and young adult volunteers dominate. Treat staged-fall detection scores as task-specific benchmark results, not clinical validation or evidence of real-world sensitivity.
